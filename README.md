# 農薬選択ゲーム

ジャガイモの栽培時期に応じて、気象・病害虫・費用・環境負荷を考えながら農薬を選ぶ学習用ブラウザアプリです。

## 使い方

`index.html` をダウンロードし、ブラウザで開いてください。写真・スクリプト・スタイルを含む単体HTMLのため、インストールやインターネット接続は不要です。

- 遊び方 → 方針選択 → 3月の農薬A使用練習 → 4〜6月の農薬選択 → 収穫・ふりかえり
- タブレット横画面を想定したレイアウト
- 年・組・番号・氏名、ふりかえりの入力
- 結果とレポートをA4横1枚のPDF、JSONで保存
- 保存名：`年1桁・組1桁・番号2桁_YYYYMMDDhhmm_nsg.pdf` または `.json`（日本時間）

進行状況や入力内容は利用するブラウザのローカルストレージに保存します。保存可否はブラウザ設定に依存します。教材中の気象・病害虫データは仮想値であり、実際の農薬使用の指示ではありません。
